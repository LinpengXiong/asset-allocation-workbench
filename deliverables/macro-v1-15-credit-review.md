# V1.15 金融信贷七项评分标准审查

研究日：2026-10-11。最新授权仅为审查清单：不改共享 app/lib/tests，不改权重，不发布。以下节点和分数是供比较的研究候选，不是已获验证或上线的规则。

## 一、结论及优先级

金融信贷七项合计20%的权重本轮保持不变。应当先修正“这个分数究竟在测什么”，再缩窄分档；不能为了更敏感，把现有值附近的区间人为变窄。

1. 必改：杠杆项改为有事实门槛、可复核的证据矩阵。居民和企业的3分不能由“缺少数据”触发；国际比率也不能单独决定分数。
2. 必改：贷款亿元阈值注明有效窗口、规模与误差边界。固定金额不能当永久、跨时期的科学分界；企事业单位不是纯私人企业，中长期贷款也不全是资本开支。
3. 必改：剔除政府债后社融两项明确其剩余口径、债务置换影响与趋势/水平重复暴露。“剔除政府债”不等于“私人信贷”，也不是核心债务；静态同比5—7%的中性带没有周期与名义增长依据。
4. 应修订：量化五项可用连续节点减轻同一档内的大幅变化被遮蔽，但具体节点仍需试行与历史验证；不因为连续分数有小数就声称更科学。
5. 需要研究：贷款规模标准化、社融增速相对名义收入的目标带、M1新口径目标区间。尚不能宣称任何候选节点是跨资产回测最优值。

主参照按用户最新要求采用BIS新兴经济体，**排除中国自身**；全部43经济体和发达组只作敏感性对照。考虑收入分布和保障制度的差异是合理的，但不能凭这一点伪造“收入不平等调整后的债务/GDP”。

## 二、国际比较：同源、同季、同口径

我的独立判断是：**中国居民债务相对新兴对照偏高，但不明显高于全部/发达经济体；中国企业债务在不同参照下均偏高。** 新兴对照更符合本工作台的主分析目的，但样本金融深度、按揭普及、收入分布和社保体系仍不同，必须结合本国趋势与现金流。低债务比率有时只是金融可得性低，并不自动是健康或高评分。

### CNBS与BIS不能混排

CNBS2026-Q1居民59.0%、企业180.0%；BIS同季为57.5%、146.6%。BIS中国公司系列从2016年起把部分估计LGFV债务归入政府，还排除股权、政府债、部分ABS和核销，并计入跨境银行债权。这不是仅靠换一个GDP分母就能消掉的差异，也不能把企业33.4个百分点差额全部称作LGFV债务。[BIS中国序列编制说明，第11—12页](https://www.bis.org/statistics/totcredit/credpriv_doc.pdf)

因此，国际比较统一BIS对BIS；中国本国趋势仍用CNBS对CNBS。企业评分需区分国企、地方融资平台与民企；政府债置换可能改变部门归属，不等于整个经济已经减债。IMF按经济活动界定政府与官方法律口径也不同，相关年度预测不当作本期实绩。[IMF 2025年第四条磋商报告](https://www.imf.org/-/media/files/publications/cr/2026/english/1chnea2026001-source-pdf.pdf)

同一经济体本币债务/本币GDP的比率无需先转美元；但外币债务估值、集团合计的汇率换算和GDP修订会影响比较。BIS未公布其全部GDP分母；用9月修订GDP去“精确重算”7月CNBS公布杠杆会制造版本不一致。当前GDP同版TTM增长4.60418%只作背景，不能假装与报告债务增速满足精确恒等式。

## 三、偿债能力：已取得数据及明确缺口

另实时取得BIS `WS_DSR/1.0/Q.CN.`。2026-Q1中国私人非金融合计DSR为19.1%，2025-Q1为18.9%。与前40季（2016Q1—2025Q4）同版平均17.74%相比高1.36个百分点；这只是本国背景。**该查询只有P合计，没有中国H/N两条分部门DSR**。BIS中国合计收入采用GDP代理，偿债模型也含期限假设；不能将19.1%填成居民或企业DSR。[BIS偿债数据](https://data.bis.org/topics/DSR)、[方法与中国来源表](https://www.bis.org/pages/statistics/dsr-documentation.pdf)

BIS明确更宜观察同一经济体的历史变化，而非将跨国DSR绝对值直接排行。Q1国际背景比Q2国内趋势更滞后，不能作为8月“当期居民偿债指标”。40季窗口也是研究约定，不是已经验证的危机线。

IMF 2025 FSAP写到居民平均DSR18.4%、约35%债务由DSR超过40%的家庭持有，但脚注说明这些数字来自**2019年央行城镇家庭资产负债调查**。它揭示均值会掩盖尾部，不能填作2026现值，更不能外推比例未变化。[IMF FSAP第35页，印刷第32页及脚注28](https://www.imf.org/-/media/files/publications/cr/2025/english/1chnea2025001-print-pdf.pdf)

当前可用代理是收入、资产/贷款结构、新发放贷款定价和工业回款。低的新贷利率不是存量债务实际偿付比率，工业回款不是全部非金融企业现金流。缺直接部门DSR时不填3；若证据矩阵的必要组缺失，则该项返回空。已有足够的相反、正向代理时可以作低置信度研判，但不据代理给4—5分。

## 四、逐项审查及建议

### F01 居民中长期贷款，2.5%权重

现定义为最近三个月新增额之和减上年同月三个月新增额之和，单位亿元。当前−2893亿元，现行2分。

- 保留：反映居民较长期信用需求变化；不用当月季节性替代三个月。
- 必改：不是贷款余额同比、不是房贷全体、不是居民偿债能力。累计新增差分得月流量须保留舍入误差，不可用余额差替代。0同比多增应是3分，不被“大于0才中性”等不对称边界误判。
- 标准候选：围绕0做线性节点，让少增程度连续变化。−2893并不与−1501完全一样，也不因−3001比−2999跨边界而产生跳跃。
- 后续研究：以同部门中长期余额或同频名义规模标准化；不能用上年新增额作分母，因为零、负值会颠倒同比含义。现阶段未核齐统一分母，不冒充已经完成标准化。

### F02 企事业单位中长期贷款，3.5%权重

当前−5700亿元，现行1分。保留资金配置时间维度，但不能称纯民间资本开支；企事业单位口径含公共单位，亦可能是展期、置换和基建融资。

- 必改与F01相同：固定亿元门槛非永久不变；原始累计值相减的误差区间应记录。
- 连续候选将−5700与极端−10000分开，而不是均为1。候选分数1.86是尺度表达，不是“融资改善”；原始量仍显著少增。
- 要观察所有贷款增速/偿债结构，而非把扩大贷款本身永远视为经济高质量扩张。

### F07 剔除政府债后社融存量同比，3.5%权重

当前5.498262%，现行3分，来自当前修订原表。

- 必改：剩余仍含国企/平台及股权等项目，不叫私人核心债务。政府债替换平台贷款时，该量可能机械下降，需口径事件注记。
- 现5—7%中性带仅为固定研究区间，缺少与当时名义收入、贷款质量的关联。不宜直接将高同比定义为可持续信用健康。
- 当前可先连续化既有档位中心；后续研究可将同频/滞后披露的名义收入增长作目标带背景。未核齐分母版本前，不能把月度同比减单季GDP或把季度数偷偷插到每月。
- 与F08同源，不把水平和变化说成完全独立两种证据；权重不变的情况下，解释其共同暴露。

### F08 剔除政府债后社融同比近三个月变化，2%权重

当前−0.240145个百分点，现3分。它是8月同比减5月同比，不是三个月同比平均，也不是新增信用/GDP的“信用脉冲”。

- 需改：中性区−0.3到+0.3会把持续回落约0.24和完全无变化都显示3分。明确0为3，以±0.3为2/4节点的连续候选会让当前约2.20分。
- 该更窄中心会放大原表修订与舍入，必须保留四期原值和复算精度，做±0.1/±0.3等敏感性比较，不在没有历史检验时叫最优信号。
- 不把它与F07、F01/F02重复映射为四次同一信用转弱扣分。

### F05 M1−M2，2.5%权重

当前−3.4个百分点，现3分。2025年新M1增加个人活期存款和支付机构客户备付金；官方回溯2024年可比值，不得拼老口径长历史。[央行公告第17号，印刷第7页](https://www.pbc.gov.cn/chubanwu/fileDir/resource/cms/2025/06/2025062416082199683.pdf)、[官方回溯表](https://www.pbc.gov.cn/diaochatongjisi/attachDir/2025/11/2025111913535682666.pdf)

- 必改：不能再把它直接叫企业资金活化率；还反映居民账户结构/理财迁移。
- 连续化可先保留已有目标型方向，左右两端均不得误作越大越好。但“0—3最佳”未被长样本/资产回报证明，只标试行。
- 本候选−3.4约3.03分，与原3分接近是正常结果；不为了使所有项目都变低而移动最优带。
- 应研究使用近三个月均值/变化以及与实际信用需求的交叉解释，新增定义须独立迁移，而非套用旧观察值。

### F09 居民杠杆约束，3%权重

国内2026-Q2杠杆57.7%、2025-Q2为61.1%，同比下降3.4个百分点；债务同比−1.3%。原文为“居民部门债务同比增长-1.3%”，不是原字段−1.2%；精确位置为[CNBS原始PDF第5页、印刷第1页](http://www.nifd.cn/Uploads/SeriesReport/b31b0f42-9b10-42dc-8732-98141ae419c4.pdf)。

主参照下建议**2.5分（试行、有限代理证据）**，不是因为只看新兴P87就降分：

- 约束证据：新兴对照相对负担高，叠加住房财富承压、消费性贷款余额下降。央行原始报告不含房贷消费贷款同比为−1.7%、个人住房贷款同比−3.8%，并非研究报告的−1.8/−3.7；采用原始值。[央行Q2贷款投向报告](https://www.pbc.gov.cn/goutongjiaoliu/113456/113469/2026072719364116939/index.html)
- 正向反证：居民名义收入+5.2%、中位收入+4.7%、工资+5.3%，本国杠杆下降；这不支持把全体居民说成“失去偿债能力”，也不支持2分或更低。[统计局上半年收支](https://www.stats.gov.cn/sj/zxfbhjd/202607/t20260715_1964129.html)
- 收入分布不能靠平均值清除，亦没有2026年借款人加权DSR供证明。−1.3%减债不是自动加分；只有收入、实际偿债和资产均支持时才可称健康修复。
- 若指标改成单独衡量违约安全、或以全部/发达组作主参照，则3分混合中性仍是合理敏感性结果。2.5适用于当前已明确的“中长期资产负债表传导约束”用途，不能伪称客观唯一结论。

### F10 企业杠杆约束，3%权重

CNBS2026-Q2为179.5%，去年174%，同比+5.5个百分点，债务+7.8%。本季环比−0.5并不能抵消同比增加。建议**2.5分（试行、有限代理证据）**：

- 结构约束：同口径BIS企业负担在所有/新兴/发达比较均靠前；本国同比杠杆上升，同时工业回款期同比延长0.9天、库存周转期增加0.6天。这些共同支持弱于完全中性。
- 实证缓冲：1—8月工业利润+15.7%、利润率提高0.44个百分点，企业新贷定价同比低0.18个百分点；因此不因比率高而判1，不把2分笼统定义必须已有危机。
- 必须限度：规模以上工业是子集，利润非现金流；公司含国企/平台，不能用上市公司盈利代替全部企业偿付能力。[统计局工业企业财务原表](https://www.stats.gov.cn/zwfwck/sjfb/202609/t20260928_1965425.html)、[央行表4，第14页/印刷第7页](https://www.pbc.gov.cn/zhengcehuobisi/125207/125227/125957/2026nhbzczxbg/2026081218435062865/2026081218435024793.pdf)

## 五、可执行候选：节点与证据矩阵

### 杠杆两项

`rule.scoring={method:'evidence-matrix',step:0.5}`；`observation.evidenceMatrix`保留国内趋势、同源国际背景、收入/盈利、直接偿债或注明代理、正反证据和季度复核。必需组不齐或事实冲突时返回空，不能补3。

| 分数 | 可核验状态，需同时满足而非单看一项 |
| ---: | --- |
| 1 | 广覆盖严重偿付/现金流失衡，并有当期直接违约/逾期或重组实证 |
| 1.5 | 多维压力明显且支持不足，尚不要求系统危机已经发生 |
| 2 | 负担与收入/现金流明显失衡，偿债或至少两组独立回收/资产压力证据偏弱，缓冲不足 |
| 2.5 | 相对负担与本国资产负债表约束联合，但收入/盈利或融资成本反证部分抵消 |
| 3 | 有完整出处的混合信号，且不满足明显约束条件；不是信息缺失默认值 |
| 3.5 | 负担稳定/下降，收入和同部门实际偿债改善，无显著相反资产证据 |
| 4 | 上述改善连续两季度，实证现金回收/DSR或保障倍数支持，分布反证已审 |
| 4.5 | 满足4分，尾部及多行业/人群改善也得到当前证据支持 |
| 5 | 4.5分条件持续且债务负担、收入、实际偿债、资产风险多维一致 |

“相对负担高”仅是事实背景，不能独自选2.5；本期居民以“缩表＋消费信贷缩减＋住房财富压力＋收入正增”联合匹配2.5，企业以“同比杠杆增加＋现金回收压力＋盈利/定价缓冲”匹配2.5。两项属于代理路径，最高3分；要3.5以上必须补当前同部门实际偿债证据。只用新贷利率下降不能触发改善档。
