# 宏观评级 V1.15：评分灵敏度与证据标准修订

信息截止：2026年10月11日。本版用于宏观背景研究，不代替股票、债券、商品各自的分析和定价框架。

## 本次范围

37项指标全部复查；指标成员和每项已确认的总分权重均不变。经济运行、增长动力、金融信贷、宏观调控仍分别占30%、30%、20%、20%。本版不以获得更高或更低总分为目标。

- 31项量化指标改用连续评分：26项单曲线、5项固定分量合成。保留1—5分解释尺度，区间内连续计算，显示两位小数；不再把同一宽档内的不同原值都压成同一整数。
- 居民和非金融企业杠杆约束改为半分档证据矩阵，不能只凭国际排名、杠杆率上升或缺少资料直接打分。
- 4项产业与制度研判继续采用整数五档，不对难以量化的判断制造小数精度；新增覆盖范围、实施条件和原始证据绑定要求。
- “评分指标”“评分标准”、总览和本期记录共用同一套算法。标准页显示真实曲线锚点、项内权重、原值、算法、来源及核验要求。

连续插值针对的是**原值到得分的函数**，不是插值补齐缺失统计数据。所有必需分量核验齐全后才能计分，缺项不补中性、不自动重分权。

## 重点修订及理由

| 范围 | 修订 | 解决的问题与边界 |
| --- | --- | --- |
| GDP实际单季同比 | 当前增长水平占项内80%，同版单季同比相对前季变化占20% | 区分4.1与4.9，并体现边际走弱；同比增速变化不冒充季调环比，年度目标也不直接当作季度目标。 |
| CPI、核心CPI、PPI、GDP平减指数 | 双侧连续曲线 | 识别零附近及修复过程的小幅变化；不把无限上涨的价格自动视为更好。各自峰值及斜率仍是研究试行。 |
| 制造业PMI、非制造业商务活动、新订单 | 近3月水平80%，相对前3月均值的变化20% | 以50为扩张收缩参照，使用两个不重叠窗口；6个月原值缺一不可。 |
| 工业利润 | 累计可比同比60%、官方当月可比同比20%、利润率同比变化10%、应收账款回收期同比变化10% | 不只看累计高增速；同时检查当月变化和盈利质量。单月值采用官方直接公布值，不从两份不同口径累计金额硬推。 |
| 工业生产、投资、商品和服务零售、出口、房价、产能利用率 | 按各自口径重设连续锚点 | 减少负增长过早封底及高增长过早封顶；保留累计、当月、季度和派生值的边界。曲线端点仍有限，不能保证无限区间都保持敏感。 |
| 信贷和货币5项 | 连续曲线，不改变指标定义 | 区分原有宽档中的信用增速、动量和贷款同比多增差异。贷款金额受经济规模及舍入影响，需后续校准，不能把细小分差当成经济事实的同等精度。 |
| 两类部门杠杆 | 新兴市场同源同季对照，结合国内债务、名义GDP、收入或盈利、资产和需求约束、反证 | 国际相对位置只是背景，不是安全阈值。国内CNBS和国际BIS口径不混算；私人非金融部门合计DSR不当作两个部门各自的偿债率。 |
| 政策利率、企业新贷利率、准备金动作 | 以零变化为3分的连续曲线 | 区分相反方向的小幅变动；准备金保留已核验的12完整月普遍调整事件账本，不反复计入窗外旧动作。 |
| 两类财政支出 | 可比执行口径下连续评分 | 不用发行进度代替资金使用，预算分母及统计期仍须核验。实际支出改善与最终产出效果分开。 |
| 4项产业与制度 | 保留整数五档，强化证据矩阵 | 4分需要明确适用范围内正式政策与可执行条件，5分还需同范围执行证据；局部行业进展不外推全经济。政策持续有效不因本月无新文件自动回到中性。 |

本版居民和企业均落在2.5分，原因是相对负担与国内约束证据共同成立，同时仍存在收入、利润等缓和证据；并非先指定低分再找理由。部门直接偿债数据不完整的限制保留可见，不将代理证据说成直接测量结果。

## 依据与仍需检验的部分

- [国家统计局SDDS国民经济主要指标](https://www.stats.gov.cn/english/Statisticaldata/nsdp/201508/t20150831_1238096.html)：本期GDP及同版前季实际同比的来源。数据发布时间和具体统计期在评分记录中另存。
- [国家统计局工业利润原始发布](https://www.stats.gov.cn/zwfwck/sjfb/202609/t20260928_1965425.html)及[解读](https://www.stats.gov.cn/sj/zxfbhjd/202609/t20260928_1965426.html)：累计、单月和盈利质量输入的依据。
- [BIS非金融部门信用数据库](https://data.bis.org/topics/TOTAL_CREDIT)：居民与非金融企业的同源同季度国际比较；明确统计范围不同于国内CNBS。
- [BIS债务偿付比率数据库](https://data.bis.org/topics/DSR)：区分利息和本金偿付负担与债务/GDP存量指标，不能把合计比率移植为部门比率。
- [欧盟JRC综合指标规范化方法](https://knowledge-for-policy.ec.europa.eu/composite-indicators/toolkit_en/navigation-page/10-step-guide_en/step-5-normalisation_en)：支持显式检查规范化选择及信息损失，**不为本项目的具体锚点、峰宽和权重背书**。

所有具体数值锚点、80/20及利润分量配比、半分档触发条件均为公开可审计的研究试行设定，尚未完成完整历史及样本外校准。实现和边界测试证明规则按设计执行，不证明预测准确、因果关系或投资收益。未来应固定规则版本，比较不同历史阶段、修订前可得数据、低基数和锚点扰动下的稳定性，再决定调整。
