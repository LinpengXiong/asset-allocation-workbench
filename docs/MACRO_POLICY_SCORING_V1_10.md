# 宏观调控评分口径 V1.10

规则入口为 `app/data/macro-rating-v1.json`，计算校验为 `lib/macro-rating.mjs`。此次只调整宏观调控，经济运行、增长动力、金融信贷及历史快照不变。以下均为研究试行规则，并非回测最优权重。

## 量化原值与算法

所有观测须有 `verified: true`、统计期、有效发布日期、原始链接；公开数据缺失留空。获取顺序为官方原始发布 → Wind → 财新。以下派生项必须存原值，人工确认可比口径后才能计分；数据结构校验不能替代原表阅读。

- 预算执行：`100 × (本年累计支出 / 本年正式批准全年支出预算 - 上年同月累计支出 / 上年同阶段正式批准全年支出预算)`，单位百分点。两类预算分别计算，不加总冒称去重后的财政支出。1—2月按合并原表，只以2月作为累计截止期，不造1月数据。记录预算调整版本与截止时点，不能将年度预算变小造成的进度上升解释为支出扩大。
- 政策利率与准备金率：`100 × (本月末有效利率 - 6个月前月末有效利率)`，原值为%，结果基点。RRR固定机构类型和适用范围；两端均核对正式生效日，不混用全行业加权平均与分档法定利率。
- 企业贷款利率：`100 × (本季末月当月企业新贷款加权平均利率 - 上年同月同口径利率)`，原值为%，结果基点。只选3、6、9、12月，不用季均、上半年均值、一般贷款利率、LPR或按揭利率替代。它测名义借款利率传导，不是综合融资成本、实际利率或融资可得性。
- 财政融资资源：只使用正式批准且不重复的额度；区分项目投入、债务置换、化债清欠、银行补资本等用途，不冒称净财政刺激。保留原先独立核验流程。

预算派生项的每期组件记录：`period, value, series, unit, basis, cumulativeExpenditure, annualBudget, budgetYear, budgetSourceUrl, budgetReleaseDate, sourceUrl, releaseDate`。`value`为当期预算执行百分比，`basis`为全国年初累计支出，`unit`为亿元。两期`series`须分别固定为一般预算或基金预算。

利率派生项每期组件记录：`period, value, series, unit, sourceUrl, releaseDate`。政策利率组件另有`effectiveDate`；RRR另有`institution, coverage`。贷款利率组件`basis`必须为“当月新发放企业贷款加权平均利率”。

## 产业和制度：判断政策条件，不承诺长期效果

四项均是有证据约束的人工原文研判，不能由文件数量自动打分。正式政策的有效性、实施条件、影响方向和副作用须由研究者逐项阅读判断。

- 1—2分：有正式依据的明显不利或偏弱条件，不能因为数据未公开而直接认定未落实。
- 3分：有证据支持的中性或正负混合判断；无证据不是3分，而是待核验。
- 4分：有效正式文件已生效，范围、工具、责任机构、实施时点明确，改善判断有依据，并说明受益、受损范围和反向证据。不等于实际资金已到账。
- 5分：满足4分，另有与主要评价范围相符的官方执行证据和执行说明；计划额度不等于拨付，名单不等于开工，压减要求不等于实际退出。无需等待利润或效率数年后兑现。

每季度及重大事件复核。录入期对应复核月，复核距离信息截止月超过3个日历月则不计分；规则仍有效、实施条件未变时可沿用对应分档，不因没有新文件自动回到3分。证据不足保持待核验。当前有效文件可早于复核月，原发布日期不改成复核日。

除通常的观测字段外，政策观测必须有`rationale`及`policyReview`：

- `reviewDate`：当前复核日，不超过截止日；`scope`：评价范围。
- `instruments, responsibleAgency, timetable, beneficiaries, risks`：工具、责任、时间安排、受益／受损主体及风险。
- `direction`：1—2分为恶化，3分为中性或混合，4—5分为改善。
- `evidence[]`：每项有主题、正式文件／执行进展阶段、标题、摘要、原始链接、原发布日期；正式文件另记录有效状态、生效日及适用的失效日。
- 5分另有`executionSummary`，至少一份执行证据的`scope`须与评价范围一致。局部试点不可冒充全国执行；范围一致仍需人工核验。

同一政策可以作为不同机制的背景，但不能凭同一个财政额度或降息动作同时给多个高分。分档理由应解释独立机制；增长动力的订单、产出、利润与产业政策不重复计分。

## 展示与发布纪律

评分指标、评分标准均展示分组权重与4／5分条件。原始发布入口不代表本期已录入观测。当前台账为空，不能生成新分数；正式总分仍要求100%权重核验。此次没有新增实际评分、收益预测或历史回测结论。所有五档数值边界和质性判断仍标试行。
