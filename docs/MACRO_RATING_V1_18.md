## GDP平减指数：区分单季与持续修复

主观察仍为本季单季同比1.526649%。每季先按原水平曲线计算，再合成：

`综合分 = 70% × 本季水平分 + 15% × 上季水平分 + 15% × 前两季水平分`

不是先平均三季原值再评分，也不把综合得分写成平减指数同比。三季均采用2026-09-15-SDDS修订版，保留各季现价GDP、上年同季现价GDP、实际GDP同比及同比指数，可按公式复算：

`平减指数同比 = [本季现价GDP / 上年同季现价GDP / (实际GDP同比指数 / 100) − 1] × 100%`

| 季度 | 同比原值 | 水平分 | 项内权重 |
| --- | ---: | ---: | ---: |
| 2026-Q2 | 1.526649% | 4.6213192 | 70% |
| 2026-Q1 | −0.0587040315% | 2.9412959685 | 15% |
| 2025-Q4 | −0.6171960835% | 2.3828039165 | 15% |

本期合成4.03353842275分，显示4.03；占宏观总分3%不变。缺季、不同修订版、公式不符或原始证据不全均不生成完整分，不重分剩余权重。

46季同版历史提供44个完整连续窗口；固定比较100%本季、60/20/20、70/15/15、80/10/10，不用当前总分挑选。70版相邻绝对变分超过0.5由单季15次变为11次、最大变分由2.1097变为1.3300，但曾有一次变化方向与单季分相反，最大偏离单季0.6086分。过去两季既可能缓冲新改善，也可能延迟反映新恶化。

本轮仅改变持续性，原水平曲线及其0.75%=4分、2%—3%峰区未重新拟合，仍需经济含义检验。平滑不等于更准确，不能宣称已验证真实经济误报率。

## 工业盈利：总量、覆盖面、边际与质量

占宏观总分4%不变，项内由四分量改为五分量：

| 分量 | 项内权重 |
| --- | ---: |
| 累计可比利润同比 | 40% |
| 行业利润改善广度 | 20% |
| 官方当月可比利润同比 | 20% |
| 营业收入利润率同比变化 | 10% |
| 应收账款平均回收期同比变化 | 10% |

从累计增长原60%中移出20%给广度，不增加指标总权重。新增广度固定覆盖GB/T 4754-2017的41工业大类，不选择某30行业，也不按缺失数缩小分母：

`B = (改善行业数 + 0.5 × 持平行业数) / 41`

`广度分 = 1 + 4B`

正基期采用官方累计可比同比：增长计改善、下降计恶化、零变动计持平。负基期须有官方明确扭亏、减亏、增亏或由盈转亏事实，不机械计算负基期百分比。41行均留当期利润金额、可比同比或特殊事实、原表值及出处，缺一行即不能生成完整广度分。

本期21行业利润增长、19下降、1扭亏，改善22/41，广度53.6585365854%，广度分3.1463414634。行业利润下降不等于行业亏损；行业合计盈利也不等于行业内没有亏损企业。电子行业62%是对总利润增长的贡献率，不是利润份额，仅作解释，不额外扣分。

累计利润15.7%、当月4.2%、利润率同比提高0.44个百分点、回收期延长0.9天等原值不动。五分量合成3.47493495935分，显示3.47，原版3.655显示3.66。固定等行业计数有规模差异局限，规模影响仍由利润总量组件保留；此广度不代表服务业、全部企业或上市公司。

50%只表示行业数量上的改善与恶化平衡，不是经济健康线。完整五组件目前只有本期1点，尚不具备全项历史校准条件，不能把部分利润历史冒充完整回测。
