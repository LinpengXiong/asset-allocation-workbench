# 宏观条件评分框架 V1.11

版本日期：2026-10-11。框架文件为 `app/data/macro-rating-v1.json`；指标、阈值、权重和解释字段由该文件作为统一来源。本说明不提供本期评级结果，不冒称已完成历史权重优化。

## 用途和边界

本框架仅为股票、债券、商品等各自的研究、估值及风险框架提供宏观背景，不直接产生买卖信号、收益预测或配置仓位。增长、价格、信用与政策支持的方向对不同资产可能不同；政策支持增强不等于实际经济复苏，工业利润也不等于全部上市公司盈利。

综合标签由“复苏／改善”改为“宏观条件较有利／偏有利／中性／偏承压／明显承压”，原4.2、3.4、2.6、1.8、1的阈值不变。标签描述框架内的综合条件，不是资产收益或已实现经济增长结论。

全部38项新增 `scoringBasis`、`thresholdStatus` 与非空 `requirements`。依据说明区分两层：官方原值和统计定义支持“测量什么”，数值边界和组内权重仍是研究设计，不是官方评级标准、样本外最优值或此次已经验证的历史优化结果。价格目标区间暂时保留，失业率和PMI历史同档比例偏高等区分度问题继续待校准。录入与核验要求逐项列出通用来源、期别、单位和口径，以及各自派生原值和特别门槛。

四类继续保持经济运行30%、增长动力30%、金融信贷20%、宏观调控20%，合计100%。所有下列比例均为占总分的权重，不是类内比例。

## 评分尺度与中性区域

数量项的1—5分描述严格对应 `mode` 与 `limits`。高优区间是左闭右开，等于阈值进入后一档；低优逆向计分，等于阈值进入偏低分一档。目标型从最内层适宜区间向外层判定，内圈两端包含，外围排除与内圈共享的边界。页面文字与实际判断必须使用同一规则。

- 居民中长期同比多增：[-1500,1500)亿元为3分，0中性；±3000亿元作为较强变化试行边界。
- 企事业中长期同比多增：[-2500,2500)亿元为3分，0中性；±5000亿元作为较强变化试行边界。
- 工业产能利用率同季差：[-0.5,0.5)个百分点为3分，0中性；±2个百分点作为较大变化试行边界。较低利用率从低基数改善，不必代表水平健康。
- 逆回购政策利率半年变化：[-5,5)基点为3分，0中性；±25基点为更大调整试行边界。
- 同类机构准备金率半年变化：[-25,25)基点为3分，0中性；-50基点落4分，±100基点作为较大变化分界。
- 新财政支出可比同比：[-5,0,3,7]仅为研究试行切点，[0,3)%为3分；官方原表支持新指标口径，不证明这套分档已经合理校准。

其余已有目标或增速区间本次保留，逐项依据在框架 `scoringBasis` 中说明。单一同比或环比高分不能直接解释为对应资产有高预期回报。固定阈值的低基数、季节和结构影响应如实在理由中报告，但不凭主观解释任意额外加扣分。

产业及制度质性项按“明显负面／承接偏弱／信号混合／正式有效且实施条件完整／再有匹配范围的官方执行证据”分档。无本月新文件不自动降为3分，缺证据不等于无效果，也不能补成中性。杠杆质性项强调收入盈利、偿付压力、GDP分母效应和反向证据，而不是越低越好。

## 新证据与时间校验

全部规则明确 `measurementBasis`、`originalPublisher`、单位和统计频率。录入必须保留原发布期、发布日期、核验截止日和最新已公布期；`latestAvailablePeriod`须与本次统计期一致，`verifiedAt`不早于原发布日、不晚于评价截止日。通过Wind或财新补充时，须另留 `sourceAudit`，记录原发布方、`seriesCode`、`officialFallbackReason`、`crossCheckNote`及可得日，解释为何官方无法满足。财新还须记录 `windFallbackReason`，说明Wind仍不能满足所需核验。来源顺序仍为官方原始发布 → Wind → 财新。

时效上限从统计期末计算：月度默认3个月、季度默认6个月。它只用于拒绝明显过期数据，不表示上限内数据已经核实为最新；发布日期不能晚于评价日。季度数据不得填成月份，年初累计不得充当单月，季度利用率不能用半年度平均替代。

- PMI三项使用不同 `componentSeries`，连续3个同系列季调原值完整才计分。
- G16主观察 `series=privateInvestmentExRealEstate`，G17主观察 `series=goodsRetailSales`，两者分别对应新 `componentSeries`，不允许旧全口径认证自动迁移。
- GDP平减指数使用同版当季和上年同季名义GDP、当季实际同比三项原值，不能跨版本推算。
- G18两期原值为全国规模以上工业的同季度利用率，原单位%，派生差的单位百分点；历史同季水平只作解释。
- G02必须另核验同口径利润率及回款质量，并留反向证据。`profitQuality`包括同一 `period`、`sameScope=true`、`comparabilityNote`、`limitations`、`profitMargin`、`receivables`、`counterEvidence`。利润率与回款子对象保留 `value`、`unit`、`period`、`scope=规模以上工业企业`、`basis`、`sourceUrl`、`releaseDate`；利润率单位%，回款证据单位天、%或亿元。反向证据保留 `summary` 和非空 `evidence`，逐项含原发布方、指标、期别、数值单位或明确事实、链接及发布日。这些用于验证及解释，不能主观二次改变增速分档。
- 两杠杆项必须有本季／上年同季原值，及复核日、GDP分母效应、收入或盈利承接、债务偿付、反向证据和具体理由的结构化记录；工业利润不能替代全部非金融企业现金流。
- P01A需两预算年同审批阶段的批准工具清单、用途、金额、批准日及同版GDP。两期资源组件均须非空 `noDoubleCounting`，解释工具间去重，尤其不能把赤字融资已包含的地方一般债再次单列；置换／再融资不计作新增资源。主观察 `period`为预算年，`reviewDate`为评价当月复核日期，不早于所用发布。年度预算继续有效时无需当月新公告；有追加时更新至截至评价日已正式批准版本。
- P01E／F保存财政部发布的可比同比、对应全国累计支出金额和可比性说明，不机械用已公布两年金额相除。缺口留空，不填估值。
- G01、G17、P01E、P01F不录伪造1月单期值，2月 `periodScope=1—2月合并`；其他投资、出口按官方实际合并发布口径保留。

本期观测另按用户要求采集截至评价日的最新原始发布，并逐项通过本版证据校验后写入。评分记录冻结当期观测、来源、缺口和完整规则，后续数据修订不覆盖原快照。每期正式总分仍要求全部评分项核验完成；未完整覆盖时只能保存暂定观察或核验记录，不补造总分。

原始公开资料的链接保留实际协议；海关官网目录提供的HTTP原始月表与研究中心HTTP报告采用严格域名限定，不伪装成已验证的HTTPS地址，也不因此放宽其他机构的来源校验。

## 未完成的验证

现有历史诊断仅涉及部分经济运行评分与未来GDP，不是按当时已知数据的历史投资回测，没有验证各类资产收益。38项的新权重、转换后的口径及质性评分仍需分别补长样本、留发布版本、检查分档覆盖，并做参数敏感性与样本外检验。新M1、服务零售及新的财政／商品／民间口径有各自样本限制，不能强行合成一条不存在的长历史。此次不宣称最优权重、不宣称完成跨资产回测。
