# 宏观条件评分框架 V1.13

版本日期及本轮信息截止：2026年10月11日。本次按用户确认的取舍，只调整财政计分构成；经济运行、增长动力、金融信贷，以及货币、产业和制度的指标、权重、五档与核验要求均不变。

## 本次变化

| 项目 | V1.12 | V1.13 |
| --- | --- | --- |
| P01A 新增财政融资工具占GDP比重同比变动 | 总分权重2.5%，可单列研究暂评 | 退出当前计分及研究暂评白名单 |
| P01E 全国一般公共预算支出累计可比同比 | 总分权重2.5% | 总分权重4% |
| P01F 全国政府性基金预算支出累计可比同比 | 总分权重1% | 总分权重2% |
| 财政政策合计 | 6%，3项 | 6%，2项 |
| 宏观调控合计 | 20%，10项 | 20%，9项 |
| 全框架 | 100%，38项 | 100%，37项 |

四大类仍为经济运行30%（8项）、增长动力30%（13项）、金融信贷20%（7项）、宏观调控20%（9项）。宏观调控内部保持货币6%、财政6%、产业4%、制度4%。上述比例均为占宏观总分的权重，而非类内比例。

## 调整依据及局限

退出P01A不是认定官方没有财政融资数据，也不是因某次取数缺口而删指标。该指标需同时处理年初审批与追加版本、专项债用途扣除、既有结存限额盘活、银行补资本及GDP核算修订，可比性和持续维护边界较复杂。本版选择以已发生的财政支出变化评价财政执行，不再把年度融资资源另行加权；年初政策资源的前瞻信息因此不再进入当前总分，应在预算原始资料和政策解释中保留。

P01E覆盖一般公共预算实际支出，P01F覆盖政府性基金预算实际支出；本轮分配4%和2%，保留财政6%总权重。两项分别按财政部全国年初累计可比同比原值计分，不以累计金额除全年预算代替，不用两年公布金额机械相除代替官方可比增速。

两项并非完全独立，都会受财政执行节奏、跨年结转及基数影响；基金预算支出也不全部等于新增基建需求。增速不能相加冒称去重后的广义财政支出，支出增长不等于净财政刺激、项目完工、经济已经改善或某类资产必然上涨。累计同比对最新边际变化的反映可能较慢。4%/2%是本轮研究结构取舍，不是回测最优值。

## 证据与评分纪律

- P01E和P01F的统计期、全国范围、官方原值、单位、可比性说明、原始发布日期及核验日要求不变；1—2月保留官方合并期，不造1月观测。
- 两项现行五档分界仍为[-5,0,3,7]，本轮不调整阈值；全部五档及权重继续标为研究试行，未完成样本外验证。
- `researchAssessmentPolicy.allowedIndicators`仅保留P02B。P01A不再参与本版研究观察分；P02B研究暂评仍与严格原值核验分开，不能替代固定机构两端法定准备金率证据，不提高原值核验覆盖率，也不能因此生成正式总分。
- 缺原值、期别、来源或复算证据不默认补中性分；最新统计期和实际数据可得日仍须核验，时效上限不是“已为最新”的承诺。
- 当前评分指标与评分标准继续共用单一框架。其余37项中除P01E、P01F的权重数字及对应定义文字外，指标定义、五档、评分依据和录入要求保持原样。

## 退休及版本留档

P01A在框架`retiredIndicators`明确登记退出版本、退出日期、原权重及原因，已从active `indicators`移除。旧版规则、原始预算资料、图表、计算候选及历史评分不删除；旧观测不能再进入V1.13当前计分。评分记录应追加新版本而非改写V1.12历史。

本文件只说明框架变更，不预先写入本期分数、核验覆盖率、档位或发布结果；这些必须由新版本规则和实际观察重新计算并另行核对。宏观评分仍仅作为股票、债券、商品等各自基本面、估值和风险分析的背景，不直接推导买卖或仓位。
