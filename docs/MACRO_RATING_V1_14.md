# 宏观条件评分框架 V1.14

版本日期及本轮信息截止：2026年10月11日。按用户确认，将准备金指标改为完整年度政策动作口径，并授权旧评分记录先备份、再清除当前展示。本文件说明规则和核验要求，不预先确认发布结果。

| 项目 | V1.13 | V1.14 |
| --- | --- | --- |
| 准备金计分项 | P02B，同类机构法定准备金率近6个月水平差 | P02E，近12完整月已执行普遍法定人民币存款准备金率调整净累计 |
| 准备金总分权重 | 1% | 1% |

其他36项定义、权重、五档、评分依据和输入要求不变。四大类仍为经济运行30%（8项）、增长动力30%（13项）、金融信贷20%（7项）、宏观调控20%（9项）；宏观调控仍是货币6%、财政6%、产业4%、制度4%。财政P01E一般公共预算实际支出累计可比同比4%、P01F政府性基金实际支出累计可比同比2%保持不变。

## 为什么改为12完整月，而不改成24个月

准备金调整是低频政策动作，6个月窗口可能很久没有变化，但没有新动作本身不代表分档错误。12个完整月兼顾政策低频与近期方向；24个月容易让已经持续有效的旧降准反复被算作当前加码。既有政策仍有效属于背景，窗口内新增动作属于本项计分，两者分开。

新指标不是机构平均准备金率，也不是固定机构两端水平的替代估值。以央行公告为原值：降准幅度记负，升准记正，1个百分点等于100基点；只累加已执行、人民币、普遍调整。普遍公告中的最低档机构除外等条件须留存，不据此改算机构加权平均。定向、行业专属、外币、机构个别调整单独记录并排除；尚未执行和窗口外旧公告只作解释。

本轮以最新已结束且官方工具原表已公布的2026年9月为期末，窗口为2025年10月1日至2026年9月30日。以后按月滚动，不把尚未结束的当前月份纳入；年月必须通过原始发布的最新可得期核验，时效上限不是“已为最新”的证明。

## 同一套五档标准

保留总分1%权重、低优模式及分界`[-100,-25,25,100]`，没有因为换观察窗而声称重新求得最优阈值。

| 分数 | 净累计幅度（基点） | 解释 |
| --- | --- | --- |
| 1 | ≥100 | 较大净升准动作 |
| 2 | [25,100) | 净升准动作 |
| 3 | [-25,25) | 动作中性，包括经完整证据支持的0 |
| 4 | [-100,-25) | 净降准动作 |
| 5 | <-100 | 较大净降准动作 |

例如0基点为3分，-50基点为4分，-100基点为4分，而不是5分。全部共享边界只归一档。上述幅度及权重仍是研究试行，未完成此新口径的长样本、样本外或跨资产验证，不是央行评分或回测最优。降准代表支持动作，并不证明信贷需求、经济增长或股票、债券、商品预期收益已经改善。

## 结构化事件账本

主观察保存`period`（期末月）、`latestAvailablePeriod`、`unit=基点`、`basis=近12完整月已执行普遍法定人民币存款准备金率调整净累计`、中国人民银行原发布方、原始出处、发布日期、核验日及可复算的`value`。规则采用独立`componentSeries=broadRrrPolicyActions`和`aggregation=近12完整月普遍法定准备金率动作累计`。旧P02B的两端水平或暂评分数不得转录。

`rrrActionLedger`包含：

| 字段 | 必须保存的内容 |
| --- | --- |
| `windowStart`、`windowEnd` | 期末月往前11个月的首日及期末月末，连续12完整月 |
| `monthlyChecks` | 12期独立完整央行工具原表；按月连续保存`period`、`tableComplete=true`、`policyReviewComplete=true`、`tool=调整法定存款准备金率`、`unit=亿元`、`injection`、`withdrawal`、`netInjection`、核验结论与原始出处、发布日期 |
| `adjustmentEvents` | 窗口内已执行事件的唯一编号、公告日、生效日、普遍/定向等分类、币种、机构覆盖及例外、`executed=true`、`unit=基点`、`signedChangeBp`、`rawChange`和原始出处；只有完整无动作证据支持时可为空 |
| `rawChange` | 央行公告带正负号的原值及原单位（百分点或基点）；百分点乘100复算，不能从流动性金额推算 |
| `crossChecks` | 跨期执行报告/大事记与政策公告复核的`type`、覆盖起止日、结论、原发布方、原始出处和发布日期；区间并集须覆盖完整窗口，不留日期缺口 |
| `reviewedSources` | 政策公告复核项下的实际已读材料：至少保留央行目录URL、结论及不早于覆盖期末的复核日，以及已读政策原文URL、结论、原发布方和发布日期；目录复核日不得晚于主观察核验日 |

动作按实质公告来源、生效日和适用范围去重，不能换事件编号重复累计。只汇总`scopeType=普遍`、`currency=人民币`且已执行的事件。月表出现非零准备金调整金额，必须与该月执行事件公告对上；其他结构性工具调整不混入。

月度工具原表单位为亿元，`—`或`-`保存原符号。这些符号只用于复核披露覆盖，**不能转换为0基点**。0基点仅在12期完整原表、已执行动作分类及跨期报告/公告复核证据均齐备后成立；缺月份、适用范围不明、仅有检索无结果或旧研究判断，一律留空，不默认3分。两类交叉证据至少包括年度执行报告/半年度大事记/季度执行报告/年度大事记之一及政策公告复核。

官方依据包括[央行流动性工具月表目录](https://www.pbc.gov.cn/zhengcehuobisi/125207/125213/5727710/index.html)、[2026年9月原表（2026年10月9日发布）](https://www.pbc.gov.cn/zhengcehuobisi/125207/125213/5727710/2026100917050827264/index.html)、[2025年度货币政策执行报告（2026年2月10日发布）](https://www.pbc.gov.cn/goutongjiaoliu/attachDir/2026/02/2026021019001885059.pdf)和[2026年上半年货币政策大事记（2026年8月12日发布）](https://www.pbc.gov.cn/zhengcehuobisi/125207/125227/125963/2026081218415997958/index.html)。实际本期账本须逐期保存12个原始URL及日期，不能用目录链接替代原值核验；URL路径中的时间不替代页面注明的发布日期。

## 旧记录、当前评分与发布边界

P02B在`retiredIndicators`登记退役版本、原权重、原因及替换编号P02E；原政策资料、图谱和退役元信息保留，不将旧口径改写为新口径。本版关闭研究暂评，量化证据不全就不补分。

本轮用户明确授权清除旧评分记录。执行顺序为先保存可恢复的旧记录及版本备份，再移除当前旧评分记录展示；备份不是清空原始指标资料，也不是事后改写历史分数。V1.14新的当前记录只能按本版37项规则和原始证据重新生成。上述授权覆盖展示记录清理，不扩大为删除原始数据或图表。

仍须全部37项通过严格核验，才能显示正式总分及正式档位；部分覆盖或缺证据不能生成正式结果。评分指标和评分标准继续读取同一框架。宏观评分仅作为各资产专门基本面、估值和风险研究的指导背景，不直接推导交易或仓位。
